CASE STUDY / 01 Course project

Issue Tracker

A full-stack issue tracker that gives teams one place to report bugs, prioritize work, and follow each issue through resolution.

The problem

Bugs and feature requests can get lost when they are scattered across messages. This tracker gives a team a central place to record issues and see their status, priority, and owner.

My role

I built the project’s Express and TypeScript API, connected it to MongoDB Atlas, integrated the React frontend, and deployed the application to Google Cloud Run.

What I built

Built with React, Node.js, Express, TypeScript, and MongoDB Atlas. The API supports creating, updating, and deleting issues; status and priority filters; search, sorting, and pagination; and issue assignment, comments, test cases, and time logs.

What I’d improve

I’d expand the React interface with forms and issue detail views for creating and editing issues, managing comments and test cases, and updating assignments and time logs. I’d also replace the placeholder user identity with real authentication.
